## 事实边界（不可改）

- 教材：**必修调整为选修 / 自读篇目、课时与篇目配比变化**，非"孔乙己被删"
- 撤销专业：**高校自主优化专业结构 + 报省教育厅备案**，非"教育部点名砍"
- 余华 / 莫言素材：仅作黑底白字字幕采样，标注"据网络流传转述，未经逐字核实"，**不生成肖像、不克隆人声**，不参与主线剧情

## 角色

不新增角色。全片需维护画面一致性的人物只有两位：**林晚**（中文系大三）、**孔乙己**。陈老师、小舟、阿哲只出声不出脸。

## 主题落点

片尾回到"书白读了的那天下午"。

## 声明

本片为虚构创作，孔乙己为鲁迅文学形象再创作，林晚等现代人物均为虚构，不指涉任何真实个人。

## 每份剧本都含「剧情梗概」与「人物小传」

三份剧本都在**角色一致性锁定**与**正片**之间插入两节可直接对外投递的文字：

- **剧情梗概** —— 一句话梗概 + 分层梗概（现实 / 课堂 / 穿越 / 片尾各发生了什么）+ 主题落点
- **人物小传** —— 林晚、孔乙己逐项钉死（年龄 / 外表 / 说话方式 / 怎么做事 / 困境 / 转折动作 / **不做什么**），
  其余角色全部按"局部处理：手、背影、声音"登记

### 角色口径（三版共用）

| 角色 | 一句话 | 处理纪律 |
|---|---|---|
| 林晚 | 她不是被启蒙的人，她是**被问住的人** | 唯一贯穿三层。转折是动作不是台词：手指停在删除键上三秒，然后拿开 |
| 孔乙己 | 他不是来救她的，他是来问她的 | 只在穿越层出现，只穿一件衣服，只在一个光照条件下。**不给出解法、不教导、不和解** |
| 陈老师 | 不下结论，只布置题目 | 全片不转正脸：手 / 3/4 侧 / 背影 / 过肩 |
| 小舟 | 那套系统里最正常的人 | 只出声：群聊文字、语音转文字、手机外放 |

> 全片只有 **2 个角色需要维护画面一致性**——这是为 AI 生成刻意压出来的，不是偷懒。
