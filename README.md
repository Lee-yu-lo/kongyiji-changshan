## 事实边界（不可改）

- 教材：**必修调整为选修 / 自读篇目、课时与篇目配比变化**，非"孔乙己被删"
- 撤销专业：**高校自主优化专业结构 + 报省教育厅备案**，非"教育部点名砍"
- 余华 / 莫言素材：仅作黑底白字字幕采样，标注"据网络流传转述，未经逐字核实"，**不生成肖像、不克隆人声**，不参与主线剧情

## 角色

不新增角色。全片需维护画面一致性的人物只有两位：**林晚**（中文系大三）、**孔乙己**。陈老师、小舟、阿哲只出声不出脸。

## 主题落点

片尾回到"书白读了的那天下午"。

本片为虚构创作，孔乙己为鲁迅文学形象再创作，林晚等现代人物均为虚构，不指涉任何真实个人。
