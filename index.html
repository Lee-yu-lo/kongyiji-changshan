不可动的定稿前提

  • 主题：他活在每一代人都觉得“书白读了”的那个下午。
  • 事实边界：教材是“调整为选修 / 自读篇目、课时与篇目配比变化”，不是被删；专业撤销是“学校自主优化专业结构、报省教育厅备案”，不是教育部点名砍。
  • 名人素材：余华、莫言只做字幕采样，无肖像、无人声克隆、不参与剧情，来源一律标注“网络流传转述”。
  • 课堂层命门：陈老师说“孔乙己在那个时代，不值得那么被精心谋杀”；林晚仍坚持写成“临死晕乎看见自己中了第”。
  • 穿越层金句：铁匣子若会写文章，还要孔乙己作甚。
  • 讽刺落点：长衫 → PPT 模板 / GPT 提纲 / API Key / 水课毕业证。不落成说教。
  • 禁止：不新增角色、不新增分支、不写成爽文、不把孔乙己写成成功学人物。

每份剧本都含「剧情梗概」与「人物小传」

三个版本都在角色一致性锁定与正片之间，插入了两节可直接对外投递的文字：

  • 剧情梗概——一句话梗概 + 分层梗概（现实 / 课堂 / 穿越 / 片尾各自发生了什么）+ 主题落点
  • 人物小传——林晚、孔乙己两个需维护画面一致性的角色逐项钉死（年龄、外表、说话方式、怎么做事、困境、转折动作、不做什么），其余角色全部按"局部处理"登记
