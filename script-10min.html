三条硬规则

  1. 跨层必换光：现实层＝屏幕冷蓝（人工光）；课堂层＝斜射日光 + 灰尘；穿越层＝单一顶光。三层三种光，不许混。
  2. 跨层必换声音底噪：现实层＝环境；课堂层＝教室混响；穿越层＝低频嗡鸣。
  3. 每段真实素材之后必须有林晚的反应镜头（反驳 / 沉默 / 划走 / 扣手机）。这既是叙事框架，也是立场缓冲。

5.3 陈老师（课堂层 · 只露手、侧身与背影）

50 岁上下的写作课教师。不下结论，只布置题目。他擦掉黑板上一半的字，说——孔乙己在那个时代，不值得那么被精心谋杀。这句话不是刻薄，是他给学生的唯一一条路：不许写时代，不许写制度，不许写"吃人的社会"，就写那一个人在最后清醒的一分钟里看见了什么。他最后一句是："但得是你写的。" 处理纪律：全片不转正脸。取手、3/4 侧、背影、过肩。

5.4 小舟（只出声 · 群聊文字 / 语音转文字 / 手机外放）

林晚的同学。她不坏，她是那套系统里最正常的人：把提示词发来发去，说"导师真看不出来"。她的存在是为了说明一件事——用 AI 写作业这件事，在她们的日常里根本不构成道德事件。

9 · 生视频执行备忘

9.1 镜头总量与拆分

  • 全片 16 场 / 78 个镜头（v1.3 删去 SC02 的技术课片段镜，79 → 78）。
  • AI 视频单次生成以 4 秒为基准单位：78 镜（平均 7.7″/镜）≈ 155–175 条生成片段。
  • SC01–SC02 与 SC04（现实层屏幕流与采样蒙太奇）几乎不需要人物生成，是全片性价比最高的两段，可优先生成、可适当加长。
  • SC05–SC08（穿越层，2′40″）是全片最贵的一段。建议：一次生成 8 秒长镜头 + 局部（手 / 嘴 / 眼）补拍，而非逐句分镜。

9.2 人物一致性（最大风险点）

  • 只需严格维护 2 个角色：林晚、孔乙己。
  • 孔乙己只在穿越层出现、只穿一件衣服、只在一个光照条件下。这是保证一致性的设计前提。
  • 林晚采用「同一件灰色连帽羽绒服 + 同一发型 + 固定景别（中近景 / 过肩）」的组合约束。
  • 陈老师、小舟、阿哲：手、背影、声音、手机头像。不生成正脸。

9.3 声音设计（比画面更重要）

  • 贯穿音：键盘声。片头第一声起（SC01），片尾最后一声停（SC16），所有层间转场用它缝合。
  • 生成音：低频嗡鸣 40–60Hz → 旧街市白噪音 → 崩解数字噪点。
  • 不用配乐，只在 SC15 用一声木鱼（或更鼓）。沉默是这部片的语气。
  • 先配音，后定时长：根据音频时长反推每格时长，不要先切画面再硬贴声音。

9.4 节奏自检

  • 前 90 秒必须出现"作业"这个具体任务 → SC01 已完成。
  • SC06–SC07 是全片唯一允许长对话的段落：42 句 / 471 字 / 约 109 秒（林晚口语按 5.5 字/秒、孔乙己半文半白按 4 字/秒估算），余 11 秒全部留给三处静默（"有吧"后、"删出去"后、"我已经穿着了"后）。这三处静默不许填音乐。
  • 剪辑时若超时，优先砍 SC06 的"水课 / 毕业证"吐槽段，保 SC07 的递衫与反问。
  • 结尾 45 秒不出现任何新信息。
  • 每一镜删掉之后自问：观众会损失什么信息或情绪？答不出就是废镜。
